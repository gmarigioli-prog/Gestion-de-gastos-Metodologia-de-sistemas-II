//  Nuestro proyecto tiene el objetivo de presentar, gestionar y analizar el historial de gastos del usuario, por lo tanto analizamos las funciones necesaria y los patrones que se pudieran aplicar en base a eso. Actualmente la aplicación cuenta con un front funcional en el que se pueden consultar y registrar datos. Actualmente no hay un patrón aplicado en la página, pero estamos considerando la adición de un botón de undo/deshacer para casos en el que se hayan realizado registros o modificaciones erróneas. Si llegaramos a agregar esa funcionalidad, aplicariamos el patrón de "memento" para implementarla, ya que este patrón esta diseñado para casos en los que se busca guardar el estado previo de un objeto (como la tabla de datos en este caso) y proporciona fácil acceso a este en caso de necesitar revertir algo.

También estamos en proceso de construit un sistema de notificaciones por e-mail.
